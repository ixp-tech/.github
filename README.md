# About the IXP organization

This repository holds the [IXP GitHub organization profile](profile/README.md). The project site is [ixp.cool](https://ixp.cool/).

The profile is intentionally a **public-facing project overview**, not an installation manual. It distinguishes verified local development features from planned functionality, does not direct visitors to the private application repository, and does not claim a public license, customers or production services.

## Editing

- Edit [`profile/README.md`](profile/README.md) when product milestones or availability change.
- Cross-check technical claims with the merged private `ixp-tech/ixp` repository's `ROADMAP.md`, `docs/STATUS.md`, code and CI results before updating the public profile.
- Use [the public website repository](https://github.com/jordaninjohnson/ixp.cool) for the landing page. The website and organization profile should agree.
- Keep links to **existing public destinations**; do not create placeholder services, badges, repositories or licensing claims.
- Date substantive content reviews, and leave unreleased features explicitly labelled as planned.

**Current visibility:** the application repository remains private with no public license or released application; the website source is public. No publicly deployable player or production service is available.
